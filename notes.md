# Рабочие договорённости

- Миграции базы ведутся в ветке Рустама; не переносить их в ветку Егора без обсуждения.
- Недочёты совместного бэкенда можно исправлять в ветке Егора, коммитить и отправлять; после этого сообщать Рустаму об изменениях и проверках.
- Остальные действия с GitHub выполнять по отдельному запросу; перед изменениями проверять ветку и состояние файлов.
- Загрузчики требуют миграции базы из ветки Рустама. Секреты и токены задаются через окружение, их нельзя помещать в код или документацию.

- Подключён PGStore: сервер использует JWT_SECRET, данные API сохраняются в PostgreSQL. Перед запуском применить миграцию 20261110000000_run_stage.sql из ветки БД. Сами миграции в ветку бэкенда не переносились.
