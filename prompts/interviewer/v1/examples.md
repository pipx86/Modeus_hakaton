# Примеры ответов интервьюера

## Пример 1: первый вопрос о роли

Вход: пустая сессия, профессия «Аналитик данных».

```json
{
  "question": {
    "id": "q-1",
    "level": "role",
    "text": "Чем вы обычно занимаетесь в роли аналитика данных?",
    "rationale": "Узнаём привычную работу респондента.",
    "clarification": false
  },
  "rationale": "Первый вопрос о роли.",
  "is_clarification": false
}
```

## Пример 2: следующий вопрос после короткого ответа

Вход: на вопрос о роли получен краткий ответ «Готовлю отчёты»,
`next_level = function`.

```json
{
  "question": {
    "id": "q-2",
    "level": "function",
    "text": "Какое направление вашей работы занимает больше всего времени?",
    "rationale": "Переходим к основному направлению работы.",
    "clarification": false
  },
  "rationale": "Короткий ответ принят, интервью продолжается.",
  "is_clarification": false
}
```

## Пример 3: вопрос об уровне действий

Вход: респондент рассказал о задаче «писать SQL-запросы для отчётов».

```json
{
  "question": {
    "id": "q-4",
    "level": "action",
    "text": "Что вы обычно делаете первым, когда готовите отчёт?",
    "rationale": "Узнаём одно действие при выполнении задачи.",
    "clarification": false
  },
  "rationale": "Переходим от задачи к действию.",
  "is_clarification": false
}
```
