# Примеры ответов интервьюера

## Пример 1: первый вопрос о роли

Вход: пустая сессия, профессия «Аналитик данных».

```json
{
  "question": {
    "id": "q-1",
    "level": "role",
    "text": "Опишите, пожалуйста, чем вы занимаетесь в роли аналитика данных и за что отвечаете.",
    "rationale": "Нужно зафиксировать границы роли перед спуском к функциям.",
    "clarification": false
  },
  "rationale": "Первый вопрос о роли задаёт границы интервью специалиста.",
  "is_clarification": false
}
```

## Пример 2: уточнение после общего ответа

Вход: на вопрос «Какие задачи вы выполняете?» получен ответ «Да всякое
бывает, по-разному», `need_clarification = true`.

```json
{
  "question": {
    "id": "q-2",
    "level": "task",
    "text": "Приведите, пожалуйста, конкретный пример задачи, которую вы выполняли на прошлой неделе.",
    "rationale": "Общий ответ нельзя подтвердить цитатой; нужен конкретный пример.",
    "clarification": true
  },
  "rationale": "Ответ слишком общий, требуется уточнение.",
  "is_clarification": true
}
```

## Пример 3: вопрос об уровне действий

Вход: респондент рассказал о задаче «писать SQL-запросы для отчётов».

```json
{
  "question": {
    "id": "q-3",
    "level": "action",
    "text": "Какими инструментами и какими шагами вы пользуетесь, когда пишете SQL-запросы для отчётов?",
    "rationale": "Для задачи нужны конкретные действия и инструменты; формулировка респондента сохранена.",
    "clarification": false
  },
  "rationale": "Спускаемся от задачи к действиям.",
  "is_clarification": false
}
```

## Пример 4: личное действие и действие команды

Вход: на вопрос о настройке CI/CD получен ответ «Мы с командой настроили
пайплайн, я писал конфигурацию, а коллеги проверяли релизы».

```json
{
  "question": {
    "id": "q-4",
    "level": "action",
    "text": "Что именно вы делали сами при настройке пайплайна, а что сделали коллеги?",
    "rationale": "Нужно отделить личный вклад от работы команды.",
    "clarification": false
  },
  "rationale": "Уточняем границу личного действия.",
  "is_clarification": false
}
```
