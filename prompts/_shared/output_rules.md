# Общие правила вывода

- Возвращай ТОЛЬКО валидный JSON-объект. Без markdown-ограждений, без текста
  до или после JSON, без комментариев.
- JSON должен строго соответствовать схеме, указанной в системном промпте
  агента (`additionalProperties: false` — лишних полей быть не должно).
- Строковые значения — на русском языке, если в схеме не указано иное.
- Все идентификаторы непустые: `id`, `source_id`, `ref_id`.
- Цитаты (`quote`) должны быть дословными фрагментами исходного текста. Не
  перефразируй, не сокращай, не исправляй орфографию и пунктуацию.
- Не добавляй поля, которых нет в схеме. Если значение неизвестно — не
  включай необязательное поле.
- Если ответ не проходит валидацию, исправь его и верни корректный JSON:
  валидатор повторит запрос с описанием ошибки.
