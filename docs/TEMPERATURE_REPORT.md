# Тесты интервьюера на разных температурах

Дата: 15.11.2026.

## Методика

Команда:

```powershell
go run ./cmd/temperature-smoke -runs 3 -temps "0,0.4,0.8" -out temperature-results.json
```

Для каждой температуры выполняется три одинаковых запроса к интервьюеру:

- профессия: аналитик данных;
- уровень: role;
- один вопрос за ход;
- модель: `nvidia/nemotron-3-ultra-550b-a55b:free`;
- фиксируется валидность ответа, уровень вопроса, latency, токены и совпадение
  вопросов между запусками.

## Фактический результат

Все 9 вызовов завершились ошибкой провайдера:

```text
Post "https://openrouter.ai/api/v1/chat/completions": read tcp ...
wsarecv: An existing connection was forcibly closed by the remote host.
```

Сводка:

| Температура | Запусков | Успешно | Ошибок | Уникальных вопросов | Средняя latency |
|---|---:|---:|---:|---:|---:|
| 0.0 | 3 | 0 | 3 | 0 | 2593 ms |
| 0.4 | 3 | 0 | 3 | 0 | 3411 ms |
| 0.8 | 3 | 0 | 3 | 0 | 4265 ms |

Токены не получены, потому что не было ни одного успешного ответа.

## Вывод

Сравнить температуры по качеству ответов сейчас нельзя: провайдер обрывает
соединение до получения ответа. Проблема не в коде: ошибки классифицируются как
`unavailable`, метрики latency и ошибок записываются.

Инструмент готов, его нужно перезапустить на стабильном VPN или локальном
Ollama. После этого появятся реальные данные по:

- валидности JSON;
- разнообразию вопросов;
- latency;
- токенам и стоимости.

## Решение по температуре

Пока оставляем интервьюеру `0.4`: это текущий дефолт, менять его без данных
нельзя. После успешного прогона сравним 0.0, 0.4 и 0.8 и зафиксируем вывод.

## Следующий запуск

```powershell
$env:OPENROUTER_API_KEY = (Get-Content .secrets/openrouter.key -Raw).Trim()
$env:OPENROUTER_MODEL = 'nvidia/nemotron-3-ultra-550b-a55b:free'
go run ./cmd/temperature-smoke -runs 3 -temps "0,0.4,0.8" -out temperature-results.json
```

Если OpenRouter недоступен, тот же сценарий можно повторить на Ollama,
переключив клиент на локальную модель.
