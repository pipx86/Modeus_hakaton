# Доступ к источникам вакансий

## Подключённый источник: «Работа России»

Используется официальный открытый API `https://opendata.trudvsem.ru/api/v1/vacancies`.
Импортёр получает JSON по поисковому запросу, до 100 вакансий на страницу, и
сохраняет только идентификатор, название, URL, дату публикации, требования и
обязанности. Контактные данные и имя контактного лица в хранилище не попадают.

Включение задаётся в локальном окружении:

```dotenv
TRUDVSEM_IMPORT_QUERY=backend developer;data analyst;devops
TRUDVSEM_IMPORT_INTERVAL_H=24
TRUDVSEM_IMPORT_PAGES=1
```

При следующем старте сервера импорт выполняется сразу, далее по указанному
интервалу. Записи имеют происхождение `trudvsem` и заголовок `[Работа России]`,
поэтому их можно отличить от данных hh.ru в цитатах и материалах исследования.

## Источники, ожидающие доступ

| Сайт | Что разрешено для подключения | Текущий статус |
|---|---|---|
| `rabota.ru` | Программный интерфейс API сайта Rabota.ru в пределах его функциональности | Нужны реквизиты и документация API от владельца доступа |
| `ru.linkedin.com` | Только официальное партнёрское API после одобрения LinkedIn | Не подключён: условия LinkedIn запрещают scraping/crawling вне API, а их Job Posting API предназначен для публикации вакансий партнёрами, не для выгрузки чужих объявлений |

Cloudflare и другие технические барьеры не обходятся. Для нового сайта до
подключения фиксируются URL, законный способ доступа, набор полей, частота
обновления, правила удаления и пример одной записи; источники, предложенные
командой, показываются владельцу продукта до импорта.
