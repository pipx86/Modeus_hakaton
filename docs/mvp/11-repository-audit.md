# Сверка реализации с рамкой MVP

**Проверено:** 21 ноября 2026 года
**Ревизия:** `bcf068b` (`dev`, совпадает с `origin/dev` на момент сверки)

## Рамка продукта

Modeus помогает методисту подготовить проверяемое дерево
`роль → функция → задача → действие`. У каждого утверждения должно быть
происхождение: материал, цитата и статус проверки. Система предлагает
сопоставления с образовательной программой, но не утверждает и не переписывает
её. Решение остаётся за методистом.

## Статус карточек

| Карточки | Инженерный статус | Что остаётся до фактического завершения |
|---|---|---|
| 1–3 | Методические документы подготовлены | Нужны подписи владельца продукта и методиста; для уровней — независимая калибровка |
| 4–5 | Аудит готовности источников и программы реализован | Нужны реальные данные выбранного пилота |
| 6–10 | Материалы, происхождение, конфликты и экран использованных источников реализованы | Проверить релевантность и права конкретных источников; цитата сама по себе не доказывает релевантность |
| 11–15 | Сценарий интервью, несколько респондентов, история и проверка оснований реализованы | Методически подтвердить сценарий; объединение всех интервью в одно дерево с явной привязкой каждой цитаты к респонденту требует отдельной приёмки |
| 16–19 | Сборка дерева, проверка узлов, снимки и сравнение снимков одного исследования реализованы | Проверить на живом пилоте |
| 20–24 | Импорт программ, компетенции/KSA, предложения связей и покрытие реализованы | Не реализованы отдельные сущности дисциплин, практик и оценочных заданий; фактическое качество сопоставления ждёт методиста |
| 25–29 | Выбор результата, единая страница, эталон, runbook и шаблон обратной связи подготовлены | 27 — подтвердить эталон; 28 — провести живой прогон; 29 — собрать и разобрать реальные замечания |
| 30 | Контроль изменения источника и отметка потенциально затронутого узла реализованы | Автоматической пересборки дерева из обновлённого фрагмента нет |
| 31 | Реализован технически, но противоречит принятой рамке | Отчёт `activity-changes` сравнивает разные исследования. Принятое решение оставляет только сравнение снимков одного дерева; этот отчёт нельзя считать частью согласованного MVP |
| 32 | Предложения по сопоставлению с программой реализованы | Решение по каждому предложению принимает методист |
| 33 | Отложена | Личный учебный план не входит в текущий объём MVP |
| 34 | Отложена | Аватар интервьюера не входит в текущий объём MVP |

## Добавлено сверх исходной рамки

- Импорт образовательной программы через проверяемый черновик, включая CSV,
  XLSX, JSON, TXT и Markdown.
- Реестр URL программ и воркер, который создаёт новый черновик при изменении
  источника.
- Адресный доступ специалиста к исследованию.
- Повтор финализации прерванного интервью и демо-учётные записи.

## Рабочее решение после сверки

По решению владельца продукта карточки 33 и 34 оставлены за пределами текущего
объёма работ. Учебный план и аватар интервьюера не реализуются до отдельного
возврата к этим задачам.

Следующий рабочий приоритет — подтвердить пилот 2/27/28/29, убрать или
отключить несогласованный отчёт карточки 31 и расширять реестр источников только
через разрешённые способы получения данных.

## Внешние сайты вакансий

Следующая запрошенная очередь: `trudvsem.ru`, `rabota.ru` и
`ru.linkedin.com`. Официальный API «Работы России» подключён. Rabota.ru ждёт
доступа к его API, LinkedIn — одобренного партнёрского доступа; обход Cloudflare
или иных защит сайта не входит в реализацию. Другие сайты, найденные командой,
показываются владельцу продукта до подключения.
