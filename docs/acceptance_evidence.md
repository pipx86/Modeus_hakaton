## Что ещё не подтверждено

- Полный продуктовый e2e с настоящими агентами, пользовательским интерфейсом и настоящим n8n. Локальная интеграционная проверка не заменяет его.
- Фактический результат GitHub Actions. Подготовлены проверки ветки БД и отдельная проверка бэкенда с чтением миграций из ветки Рустама; после отправки необходимо проверить их выполнение.
- OCR сканов и универсальное извлечение компетенций из произвольной вёрстки. Поддержаны структурированный JSON и распознаваемые текстовые разделы программы.

Настройка hh.ru хранится зашифрованно вне репозитория. Если владелец заменит общий токен, нужно предоставить загрузчику актуальный; скрипты не выполняют его обновление или отзыв.
