# Миграции базы данных

Миграции рассчитаны на PostgreSQL и выполняются инструментом Goose. Команды ниже запускаются из корня репозитория. `DATABASE_URL` должен указывать на отдельную тестовую базу PostgreSQL; не сохраняйте реальные пароли в репозитории.

В Git Bash:

```bash
export DATABASE_URL='postgres://USER:PASSWORD@localhost:5432/DBNAME?sslmode=disable'
goose -dir migrations postgres "$DATABASE_URL" up
goose -dir migrations postgres "$DATABASE_URL" status
```

Для проверки отката одной миграции и повторного применения на чистой тестовой базе:

```bash
goose -dir migrations postgres "$DATABASE_URL" down
goose -dir migrations postgres "$DATABASE_URL" up
goose -dir migrations postgres "$DATABASE_URL" up
```

`down` откатывает последнюю применённую миграцию: конкретные действия определяются её разделом `-- +goose Down`. Откат может удалить таблицы, столбцы, связи и их данные; перед откатом в базе с нужными данными сделайте резервную копию. В проверенной версии Goose команда откатывает одну миграцию. Второй `up` должен сообщить, что миграций для запуска нет.

## Проверки дерева и доставка события

- Уникальный индекс `(parent_id, title)` запрещает точные повторы названий у одного ненулевого родителя. Дополнительные отложенные проверки требуют корректного корня для каждого непустого дерева, учитывают пробелы по краям названия и проверяют наличие подтверждений. Одинаковые названия в разных исследованиях допустимы.
- При переходе `runs.status` в `done` триггер записывает событие `run.completed` в очередь `agent_messages`. Уникальный индекс не позволяет создать второе событие `run.completed` для того же исследования.
- Миграция сама не вычисляет HMAC и не выполняет HTTP-запрос. Отдельный процесс `cmd/webhook-worker` читает очередь, подписывает и отправляет событие. Выбранный формат описан в `internal/webhook/README.md`; реальный n8n и запуск обработчика вместе с приложением ещё нужно проверить.

Пакет `migrations_optional/vector` применяется отдельно и требует pgvector. Его порядок и откат описаны в `migrations_optional/vector/VECTOR_STORAGE_GUIDE.md`.
