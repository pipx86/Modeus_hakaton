# Unit-тесты backend

Запуск всех unit-тестов из корня backend-репозитория:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\unit\run.ps1
```

Тесты запускаются одной командой для всех Go-пакетов. Их исходники остаются рядом с проверяемым кодом: так тест принадлежит тому же Go-пакету и может проверять его внутренние функции и типы. Если такой тест перенести в `tests/unit`, он станет другим пакетом и потеряет доступ к этим внутренностям. Тесты только публичного API можно размещать в этой папке.

Запускатель временно очищает переменные PostgreSQL и Ollama только для процесса проверки и затем восстанавливает их. Поэтому тесты, которым нужна настоящая PostgreSQL или Ollama, пропускаются, а локальные переменные пользователя не меняются.
