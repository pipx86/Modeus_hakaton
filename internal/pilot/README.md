# pilot: аудит данных пилота

Пакет проверяет, хватает ли данных для пилота, и ничего не меняет в базе:

- **карточка 4** — источники по пилотной профессии;
- **карточка 5** — структурированные данные выбранной образовательной программы.

## Запуск

```powershell
$env:DATABASE_URL = "postgres://postgres:postgres@localhost:5432/activity?sslmode=disable"

go run ./cmd/pilot-audit -profession "аналитик данных"
go run ./cmd/pilot-audit -program <uuid программы>
go run ./cmd/pilot-audit -profession "аналитик данных" -program <uuid> -json
```

`-json` выводит объект с полями `sources` и/или `program` (в зависимости от выбранных целей).

DSN берётся из `-dsn` или `DATABASE_URL`. Коды возврата:

| Код | Значение |
| --- | --- |
| `0` | Отчёт построен. Статус может быть «готово» или «требует внимания» |
| `2` | Ошибка конфигурации, неверный UUID или недоступная база |

Команда только читает данные. Ошибка импорта или схемы ею не исправляется.

## Как читать статусы

`Статус: готово` — выполнены правила готовности. `Статус: требует внимания` — хотя бы одно правило не выполнено; конкретные причины перечислены в разделе «Проблемы». Проблемы могут быть и у готового набора: например, отсутствие совпадений с анализатором или отсутствие структурных дисциплин не блокируют MVP.

### Источники

Готово, если одновременно:

- всего не меньше 5 источников;
- не меньше 3 разных типов;
- есть хотя бы один источник одновременно с непустым текстом и URL.

В строке типа: `всего / с текстом / с URL / с датой / пригодных`. «Пригодный» — с текстом и URL; дата учитывается отдельно. «С датой» — заполнен `created_at` или `vacancy_published_at`. `Анализатор` — существующий адаптер вакансий hh (`store.NewVacancyAdapter`): учитываются только его совпадения с выбранными источниками.

### Программа

Готово, если одновременно:

- программа найдена по ID;
- не меньше 3 компетенций;
- не меньше 5 KSA;
- есть хотя бы одна связь компетенции или KSA с таксономией.

Дисциплины и результаты обучения в текущей схеме не структурированы: соответствующих таблиц нет, поэтому отчёт честно пишет «только в документах». Это ограничение MVP, а не ошибка программы.

## Ограничения

- Аудит не заменяет проверку смысла источников и не проверяет дубли, права и обезличивание.
- Поиск по профессии — `ILIKE` по отдельным словам с приоритетом источников, где совпало больше слов; это эвристика, а не семантический поиск.
- Отдельной даты материала схема не хранит: `Dated` опирается на дату импорта и дату публикации вакансии.
- Наличие дисциплин и результатов обучения определяется только по именам таблиц, а не по строкам конкретной программы.

## Тесты

