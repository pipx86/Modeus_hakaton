# Политика обработки персональных данных

Настоящая политика описывает, какие персональные данные собирает сервис
оценки компетенций и как они обрабатываются в соответствии с Федеральным
законом от 27.07.2006 № 152-ФЗ «О персональных данных». Пользуясь сервисом,
вы подтверждаете, что ознакомились с политикой и даёте согласие на обработку
указанных ниже данных.

## Какие данные мы собираем

- адрес электронной почты и отображаемое имя, указанные при регистрации;
- хеш пароля (сам пароль в открытом виде не хранится);
- служебные данные согласия: версия документа, дата и время принятия,
  IP-адрес и User-Agent устройства;
- материалы исследования: профессия, транскрипты интервью, ответы, цитаты,
  деревья деятельности и связанные с ними отчёты;
- необязательные данные, которые вы передаёте сами: текст резюме или профиля,
  ссылку на публичный профиль GitHub и его открытые данные.

## Зачем мы обрабатываем данные

- создание и обслуживание учётной записи, аутентификация и авторизация;
- проведение интервью и автоматизированный анализ компетенций;
- формирование результатов исследования, отчётов и рекомендаций;
- обеспечение безопасности, предотвращение злоупотреблений и поддержка.

Мы не используем данные для рекламы и не продаём их третьим лицам.

## Где и как хранятся данные

- данные хранятся на серверах сервиса в PostgreSQL; доступ к ним имеют только
  уполномоченные администраторы и сервисные компоненты;
- передача данных между браузером и сервером защищается по HTTPS;
- доступ к API возможен только по JWT, выпущенному после входа;
- данные хранятся не дольше, чем нужно для работы сервиса, либо до отзыва
  согласия, если иное не требуется законом;
- при удалении учётной записи связанные записи согласия удаляются каскадно.

## Ваши права

- получить информацию о том, какие ваши данные обрабатываются;
- потребовать уточнения, блокирования или удаления данных;
- отозвать согласие на обработку персональных данных;
- обратиться с жалобой в уполномоченный орган по защите прав субъектов
  персональных данных.

Отзыв согласия останавливает обработку, но может сделать невозможным
дальнейшее использование сервиса.

## Контакт

По вопросам обработки персональных данных и для реализации своих прав
напишите на privacy@modeus.local. Мы отвечаем в срок, установленный
законодательством Российской Федерации.
