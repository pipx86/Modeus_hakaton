# Отправка событий

Пакет `webhook` отправляет JSON по HTTP POST. На текущем этапе используется предварительный формат: заголовок `X-Webhook-Signature` содержит HMAC-SHA256 от точных байтов тела запроса, закодированный строчными шестнадцатеричными символами. Получатель должен проверять подпись по исходным байтам тела запроса. Формат заголовка и подписи необходимо согласовать с n8n.

Приложение передаёт адрес и секрет в `NewSender`; секрет должен поступать из настроек окружения, а не из репозитория. `Send` сообщает об ошибках сети и HTTP-ответах вне диапазона 2xx. Повторную отправку, учёт попыток и обновление `agent_messages` должен выполнять вызывающий код.

Пакет сам не читает очередь и не запускается при изменении `run`. Чтобы завершить интеграцию, нужно подключить отправщик к сохранённым событиям, настроить обработку повторов и проверить взаимодействие с реальным workflow n8n. При повторной отправке получателю потребуется дедупликация события.
