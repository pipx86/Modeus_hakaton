Demo chat (JWT protected)

Generate a local token, create a run and read the interviewer fallback questions. The API uses the in-memory store, so data resets on restart. 

TOKEN=$(docker compose exec -T api /local-token -role admin)
curl -s -X POST http://localhost:8080/api/v1/runs \
  -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"profession":"аналитик данных"}'
curl -s http://localhost:8080/api/v1/runs/run-1/messages \
  -H "Authorization: Bearer $TOKEN"
